# ch-bsd — refmatrix overlay

Read with the neutral `.claude/agents/ch-bsd.md`. Facts the auditor needs for THIS project.

## Production roots and how code gets executed

- `src/refmatrix/` is production. Entry points: `rmx` console script → `cli.py:cli_entry` (click
  tree); daemon ops via the `OPS` / `CLI_OPS` dicts in `daemon.py` (an `_op_*` not registered
  there never runs); hub ops in `hub.py`; MCP tools = the `TOOLS` list in `mcp.py` dispatching to
  `verbs.py` (`@verb`) — a tool that calls daemon/handoff directly bypasses the capability layer;
  hooks generated by `hooks.py:_claude_hook_block` + `search_hooks.py` — the INSTALLED file is
  `.claude/settings.json` (rmx block) and must equal the generated block (`rmx install-hooks --check`).
- Templates shipped to other projects: `src/refmatrix/templates/{commands,agents}/`.
- The deployed runtime is `~/refmatrix/.venv` behind `~/bin/rmx`; verify what it imports with
  `~/refmatrix/.venv/bin/python -c "import refmatrix; print(refmatrix.__file__)"`. Dev is `.venv-eval/`.

## Where deferrals hide (Python)

Module docstrings ("Phase N", "deferred to v1", "for now"), `# TODO`, `_ = unused`, env-flag-only
facades (`RMX_*` read once, no caller), `except Exception: pass` on write paths, and `|| true` /
`2>/dev/null` inside generated hook strings.

## E2E

No browser suite. The end-to-end paths are: `rmx save-state` → `rmx recall-state` round trip on a
tmp store; `rmx install-hooks --check`; the verb parity test (`tests/test_verb_parity.py`); the
production benchmark harness `eval/production/`.
