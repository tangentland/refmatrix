## What to check (at minimum) {#check}

1. **Reproduce headline numbers** from the scripts on fresh read-only APFS copies: the pilot's
   per-band label counts and `p_w`; phase 1's file/name vs term vs clique stratified O/E and the
   placebo DiD; the two control defects (dead-on-arrival units, prior-touch in the control) and the
   corrected cliquedb lift (+0.30, not −0.50); phase 2's GMD `rel:` gap (66.9% / 80.8%); phase 3's
   λ lift counts and AUC.
2. **Label validity:** one rater per pair, five forks, one uneven rubric call. Re-label a blind
   sample (≥ 20 pairs drawn by your own seed, half headline, half control) without seeing the
   original label; report agreement on CAUSED+INFORMED vs not. Is "CONSISTENT" being used for
   cases where the delivery plausibly prevented a detour?
3. **Placebo design:** within-project sessions share vocabulary; does the placebo prove "term
   overlap is not use", or only "term overlap cannot distinguish use within one project"? State
   which conclusion the data supports.
4. **Stratification:** could the strata (kind × channel × term-count) absorb a real effect? Are
   strata with < 20 control units dropped in a way that biases O/E?
5. **Phase 2 GMD gap (bug-216):** is the 67-81% real or an artefact of the file-level probe
   (anchor entities vs file entities, concept targets, `imports:`)? Reproduce on 3 docs by hand.
6. **Phase 3 pre-registration:** was it really written before the results (file mtime vs output
   mtimes)? Are the post-hoc λ rows labelled post-hoc everywhere?
7. **Privacy:** confirm no committed file contains prompt text, commands, reply text or memory
   bodies; `views/` stays in the scratchpad.
8. **Conclusions vs evidence:** for each verdict line, the strongest alternative explanation the
   measurement does not rule out.
