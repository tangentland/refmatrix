## BULLSHIT {#bullshit}

### B1: the GMD rel: gap — bare doc-id targets bind a same-named path-less concept {#b1}

- **Direction confirmed:** `rel: X verb -> Y` is stored as `entity_links(entity_id = Y, concept_id = X)`.
  It is NOT the cause: `phase2.py` walks both directions (`:165-169`, `:284-288`). The lead's
  correction note's mechanism is wrong.
- **Cause:** `ingest_gmd._resolve_target_eid` (`:489-509`) checks the batch dict, then
  `store.get_entity` for `("concept", "doc", "memory")` in that order, and caches the hit. A bare
  doc-id target outside the current batch binds a same-named path-less CONCEPT (minted by
  `store.add_concept` variants joined by `same_as`, or by the plain-wikilink mentions branch
  `:1755-1770`) — even when the concept was created after the doc. Within one batch, pass 1's
  `eid_by_name[doc_id] = doc_eid` (`:1438`) binds the doc. Anchored links bind correctly.
- **Hand-checked ids (refmatrix clone 12:30):** `hypertree.md:34` derives-from → spike-2026-10-07-adjacency-shape
  lands on concept 7622381 (path NULL; `same_as` 7622379), doc entity 7621319; `hypertree.md:36` →
  concept 7500929 (doc 7752144); `plan-21-agent-context-usage.md:28` → concept 7500932 (doc 8619111);
  `:33` → concept 8491808 (doc 10208058). Correctly bound: `plan-21:34` → doc 9298853 (no
  same-named concept); ADR-0004:15 → doc 7502694. Memory targets with no doc/memory of that name
  land on "GMD anchor" concepts (3173084, 761413).
- **Counts (refmatrix):** bare-id lines whose target name is both a doc and a concept: 2,967 —
  2,727 bound the concept, 240 the doc. Of 3,594 authored wikilink `rel:` lines: evidence row
  87.1%; live edge 68.1%; live AND target has a path 29.2%; live path-less concept 39.0%; evidence
  but no live edge 19.0%; no evidence 12.9%.
- **Metapaths:** direction-neutral; but a hop-1 GMD metapath reaches the cited doc only for bound
  lines (~29-33%), and hop-2 paths through a path-less id concept reach other docs citing the same
  id — the GMD-provenance combos largely measure co-citation.
- **Fix:** state concept-first binding in bug-216 and `#gmd-gap-correction`; the R8 recount joins
  a live `entity_links` row with both entities present; re-run phase 2 after the fix.

### B2: the placebo is asymmetric {#b2}

`tc.py score_units` builds the prior context from the REAL session before swapping in the placebo
session, so the placebo session's own ongoing work counts as new. Symmetric re-run (`tc_sym.py`):
refmatrix main-loop new terms 2.67% real vs 0.62% placebo (+0.39 pt vs the control's placebo), all
new terms 3.07% vs 0.75% (+0.50); cliquedb 0.54% vs 0.08% (+0.03), 1.00% vs 0.16% (+0.19). "Unrelated
sessions contain the items' new terms as often" is an artefact. Term and clique verdicts survive on
the stratified control comparison only.

## Design answers {#design}

- **Placebo:** once symmetric, it supports "the real session's later work contains the item's new
  terms ~4× more than another session's" (relevance, continuation). The same-session never-delivered
  control is what separates use from relevance, and it shows no excess.
- **Stratification:** strata are fixed before delivery, so they cannot absorb an effect directly; the
  min-20 rule hides the delivered-only doc-anchor strata (S2).
