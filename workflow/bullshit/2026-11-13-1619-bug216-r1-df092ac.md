### BULLSHIT B1: `rmx ingest <memdir>` now stores memories as `kind=doc`; at 758bca1 it stored nothing {#b1}

**File:** `src/refmatrix/ingest.py:280-281` (`base` defaults to `root`), used by `_ingest_tree`
`:1314` (`should_ignore(p, root)` with `root` = the ingest target). Reached from:
- `rmx ingest PATH` (`cli.py:8221-8226` → `_ingest` → op `ingest_path`, `daemon.py:3643/3649`);
- the MCP verb `rmx_ingest(path=…)` (`verbs.py:1254`).

**What:** R2-base (AC-17) applies the hidden-directory and `INGEST_IGNORE_DIRS` segment rules only
to the parts BELOW `base`, and `base` defaults to `root`. For `ingest_path`, `root` is whatever
directory it was given. At 758bca1 the hidden-dir rule read the absolute path, so a target under
`~/.claude/…` was excluded wholesale. At df092ac the target's own hidden ancestors are never
checked.

**Why it's bullshit:** this breaks the user's verbatim condition on R2: "as long as the files
hidden directories don't pollute the graph because of incorrect classification". It also opens a
second door to bug-220 (memories written as `kind=doc`) that did not exist before. The X1 pins
(`test_bug216_hidden_no_pollution.py`) test `project-ingest-path` only on the project root, so this
route is not covered. Rule-10 shape: the fix worked for the walkers it was aimed at (watcher, sync)
and quietly widened a third.

**Evidence** (scratchpad `probe_memdir.py` / `.log`; one throwaway store; the same script run
against both trees):

```
== base (758bca1)
ingest_path(home/.claude/projects/x/memory) -> 0; rows=[]
ingest_path(proj/.claude) -> 0; rows=[]
== df092ac
ingest_path(home/.claude/projects/x/memory) -> 2; rows=[('doc','feedback_a'), ('doc','feedback_b')]
ingest_path(proj/.claude) -> 1; rows=[('doc','agent-x'), …]
```

Both memories land as `kind=doc`. An agent template from `.claude/agents/` lands too, although the
spec says "the rest of `.claude/` … stays out" ([[task-bug216-rule-docs-in-graph#why-consistent]]).

**Fix:**
1. Before merge, `ingest_path` should read the spec AND apply the segment rules relative to the
   PROJECT root (`find_project_root(path)`), not relative to the target. An explicit carve-out like
   `collect_gmd_files`' `base=t` is the precedent if `rmx session ingest` needs one.
2. A memory-dir target (ADR-0005 marker or `~/.claude/projects/*/memory`) is refused with a loud
   error, or routed to the memory path. Routing is bug-220's decided fix, so add an order edge
   bug-216 → bug-220, or land bug-220's ROUTE first.
3. Add `ingest_path(<memdir>)` and `ingest_path(<proj>/.claude)` rows to the X1 pin table. Both must
   fail at df092ac.

**Pattern match:** YES — `imp-one-control-point-is-a-census`. The central `base` default changed

### SKETCHY S2: `pending_refs` is missing from both table-copy paths, so rows are lost on a slot merge or partition merge {#s2}

**File:** `src/refmatrix/replica_merge.py:84-88`, `:527-531`, `:629-633`;
`src/refmatrix/store.py:1779` `merge_partition`.

**What:**
- **Slot merge.** `merge_slots` builds a fresh target with `init_catalog` and copies only the listed
  tables. `pending_refs` is not listed, so `_op_replica_merge` (an operator op, `rmx` replica
  merge) leaves it empty.
- **Partition merge.** `merge_partition` re-parents entities, `saved_queries` and `tracked_files`,
  and remaps `linkage_evidence` on id collisions. It never touches `pending_refs`, so the source
  partition's rows keep a dead `partition_id`, and on a collision they keep a deleted
  `source_id`. They can never resolve and are never cleaned up.

The summary's `#green-migration-story` names the replica gap and defers it in its own words.

**Why sketchy:** rev 5 rejected exactly this loss for the rebuild: "a rebuild would silently lose
dangling refs that should bind later" (`task-bug216-rule-docs-in-graph#rev-5-why`). The same
silent loss stays on two sibling paths. The citers are unchanged, so nothing re-records the rows.

**Fix:**
- Add `pending_refs` to the three `replica_merge` table lists, with a `source_id` remap like
  `linkage_evidence`'s.
- In `merge_partition`, `UPDATE pending_refs SET partition_id=dst` and remap `source_id`.
- Add one test per path that fails at df092ac.

**Pattern match:** YES — `imp-table-needs-facts-log`, `imp-one-control-point-is-a-census`.
