### SKETCHY: L87 S3 is only half folded: `shrink` can still fire on a test that has no power {#s2}

The push reading still reads `shrink` "when A is better on none" (28.4:63, 28.3 R9, plan-28
#bands). Two problems remain.

1. **No non-inferiority rule.** L87 requires `shrink` to need non-inferiority within a
   pre-registered δ. There is no δ and no non-inferiority test anywhere.
2. **The clamp keeps underpowered readings alive.** Under the new rule, when `n_power > 20` the
   minimum is 20 and the reading still runs. The file states the larger effect that 20 can
   detect, as a limit. With a "better on none → shrink" rule, an underpowered push test still
   reads `shrink` on noise. That is exactly what L87 S3 forbids: "an underpowered or noisy test
   can never read `shrink`".

**Fix:**
- Add to 28.4 R2 and 28.3 R9: `shrink` requires each of (2)-(4) to be non-inferior, with the
  Holm-adjusted CI of B − A excluding worse than δ. Pre-register δ in 28.4.
- Otherwise the push reading is `no verdict`.
- AC-8 gets a noisy, wide-CI set that reads `no verdict`, not `shrink`, with the mutation
  "non-inferiority check removed".
