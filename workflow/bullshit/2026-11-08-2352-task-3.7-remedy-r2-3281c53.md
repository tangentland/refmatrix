## Findings {#findings}

### SKETCHY: a rebuilt daemonless embed client never goes back to the hub. bug-024 reborn in the MCP process {#s-1}

**File:** src/refmatrix/recall.py:376 (docstring), :354-365 (`_embed_client_is_dead`)
**What:** The docstring promises that the rebuild yields "a private worker while the hub
stays down, the hub again once it answers". `_embed_client_is_dead` judges only a
`SharedWorkerClient`, and a private `WorkerClient` is never rebuilt. So once the process
falls back to private, nothing ever re-probes the hub.
**Why it is a problem:** The probe restarted the hub and made two more calls (5, 6). Both
used `stub/private` on the same client. The process keeps its own model worker (~610 MB)
for the rest of its life, even though launchd respawns the hub within seconds. This is
the shape of bug-024, which `Daemon._maybe_adopt_shared` fixed for daemons (task 12.1). It
matches memory `project_shared_worker_private_split`. Before R-H1, each call ran
`new_model_client` and re-adopted the hub. R-H1 plus R2-S1 traded that recovery for the
cache. The docstring describes recovery that cannot happen.
**Evidence:** `bsd-r2-probe-embed-client.log` lines "5 hub restarted / 6 hub restarted
ok model=stub/private client=Priv@1051ce120 rebuilds=1".
**Fix:** In `_process_embed_client`, re-probe `modelsrv.shared_available()` while the
cached client is private. Throttle it with the daemon's backoff
(`RMX_SHARED_REPROBE_S` / `_MAX_S`). On success, swap and close the private worker. Or, as
a minimum, correct the docstring and register a deferral row with a task.
**Pattern match:** YES (bug-024; r1 #s-1 "a cache must forget a dead entry").

### SKETCHY: the load-bearing `not client.alive()` gate survives mutation {#s-2}

**File:** src/refmatrix/recall.py:364-365
**What:** Mutation M3 replaced `not client.alive()` with `True`, so every call rebuilds the
handed-out shared client. 62/62 tests still passed. The fix's whole design rests on
`alive()` == "socket held", and no test pins it. R2's hub test makes only ONE call before
the kill. R13 uses a non-shared fake client.
**Why it is a problem:** Under M3 a healthy hub-backed MCP process closes and reconnects on
every call, logs "lost its connection" falsely, and bumps the rebuild count on every
call, and the suite stays green.
**Fix:** In `test_a_hub_crash_does_not_pin_the_process_to_its_dead_shared_client`, make two
calls before the kill and assert that both return the same `SharedWorkerClient` and that
`_EMBED_CLIENT_REBUILDS` is unchanged.
**Pattern match:** YES (post-impl M11/M18 surviving guards).

### MEH: on the production path the rebuild notice and its counter reach no one {#m-1}

**File:** src/refmatrix/recall.py:385, :417
**What:** The daemonless verbs call `shared_embedder(root)` with no `log`, so `say` falls
back to `logging.getLogger(__name__).info`. Neither `mcp.py` nor `cli.py` configures
logging, and the `lastResort` handler drops INFO. The probe without an injected log
wrote 0 bytes to stderr across a crash and a rebuild. `_EMBED_CLIENT_REBUILDS` has no
reader outside that dropped line. The test passes `log=logs.append`, which hides this.
**Fix:** Surface the rebuild at WARNING, or through a status/verb field. The same applies to
the pre-existing "falling back to in-process model -- loudly" line, which is just as
silent.

### MEH: the `_EMBED_CLIENT_ISSUED` conjunct is vacuous in production {#m-2}

**File:** src/refmatrix/recall.py:364, :399
**What:** Every cached client is assigned to `_EMBED_CLIENT_ISSUED` in the same critical
section that creates it. `new_model_client` connects a shared client by its `info()`
probe (:305) before returning it, so the "never handed out, lazily connected" case the
docstring guards cannot arise. Mutation M4 dies only because test 2 seeds the global
directly. Without the conjunct, that seeded scenario would rebuild at once and skip the
in-process load that the test asserts. The guard protects a test shape, not production.
The rig also leaks `_EMBED_CLIENT_ISSUED` / `_REBUILDS` / `_ATEXIT` across tests (only
`_EMBED_CLIENT` is monkeypatched).
**Fix:** Drop the conjunct and make test 2 expect the immediate rebuild. Otherwise, justify
the conjunct with a reachable production case. Monkeypatch all four globals.

### MEH: R13's atexit assertion went vacuous {#m-3}

**File:** tests/test_task3_7_remedy_r1.py:307-315
**What:** The spy counts only registered functions named `close`. The closer is now
`_close_process_embed_client`, so `len(closes) <= 1` always holds at 0. Mutation M6
(register atexit on every rebuild) survives.
**Fix:** Count `_close_process_embed_client` registrations, or count every `register`
call from `recall`.

### MEH: the three clauses of the R2-M3 path-shape rule are untested one by one {#m-4}
