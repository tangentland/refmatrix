### MEH: the start commit leaves `end` unset, so a fixed 72-hour period depends on a later, user-gated commit {#m2}

**File:** `task-28.5-run-and-report.md:57-59` (R2), `:86-89` (R4).

R2's start commit sets only the salt and the start. R4 sets `end` "3 calendar days after the
start" by a separate commit, and the end is a user step. If that commit lands late, `arms.draw`
keeps randomising sessions past 72 hours. That breaks "never extended" (L79), and those
sessions fall inside the record's window and would be scored.

**Fix:**
- R2's start commit sets `end` = start + 72 h in the same record, so the draw closes on its own.
- R4 becomes the check after the end (`draw` returns the default) plus the user step.
- The scorer drops any session whose SessionStart `t` is at or after `end`, and counts it.
