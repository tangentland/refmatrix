## Findings {#findings}

### SKETCHY s1: bug-155's test now passes without running lint {#s1}

`scripts/lint-gmd.sh:34-39` exits 2 ("dev interpreter not found") before lint runs in any tree
without `.venv-eval` (every littlebig clone, CI). `tests/test_gmd_lint_requires_version.py:134-137`
checks only lines containing ": error", never the return code: it passes at HEAD in 0.13 s while
the gate exits 2, fails at base, and fails in the merged tree once `.venv-eval` is linked. Fix:
assert `returncode != 2` and no "not found at" line; bug-155 stays the clone-only known failure.

rel: contradicts -> [[claude#no-silent-failures]]

### SKETCHY s2: CI can never pass the new gate {#s2}

`gmd-lint.yml` runs only `setup-python`, so the parity precondition exits 2 on every push and PR;
the spec's `#f-gates` missed this workflow. Parity needs `pyroaring` beyond the stdlib. Fix: build
`.venv-eval` in the workflow (or an interpreter override CI sets); do not make the step optional;
add CI to `#f-gates`.

### SKETCHY s3: "a crash never passes" is pinned by no test {#s3}

Mutation `n = len(divergences) + len(failures)` → `n = len(divergences)` in
`check-gmd-parity.py`: all 38 tests green. Fix: plant a non-UTF-8 doc carrying `gmd:`; assert exit
1 with `[parity-parse-fail]`, and that `find_divergences` raises.

rel: contradicts -> [[claude#no-silent-failures]]
