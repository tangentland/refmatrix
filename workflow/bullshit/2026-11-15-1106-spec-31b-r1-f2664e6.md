## Open findings at `f2664e6` {#findings}

### B1 (31.1): on the sync route the refused file loses its rows and the refusal goes quiet {#b1}

**Where:** `#r2-sync`, `#r2-row`, `#ac-4`, `#ac-5`. Both revisions leave them unchanged.

**What the spec says:**

- The refused file's previous doc and anchor rows "are kept as they were".
- A re-queued refused file keeps "the recorded error until the file is fixed".
- AC-4 asserts that the bad doc's previous rows and anchors are unchanged.

**The rows are not kept** (`bsd31b-r1-sync-rows-probe.log`):

- Every sync runs `_ingest_markdown_semantics` over `touched_existing`, and that includes the
  GMD paths (`sync.py:374`).
- That pass creates a relpath-named `doc` row and calls `mark_tracked`
  (`ingest_records.py:242`).
- On the next edit, `_sync_one`'s guard (`sync.py:269-271`) runs `purge_path` on the whole
  path, before the GMD pass refuses the file.
- So the doc-id row and the anchors are gone (`adoc` and `adoc#sec` deleted; only a fresh
  `docs/a.md` (16) is left).
- AC-4 cannot pass under the spec's own design.

**The error does not stay:**

- The refused path still goes through the semantic pass, so its mtime is stamped.
- The retry sync touches 0 paths: the mtime gate skips the file, and `_gmd_route_pending`
  returns `False` because its own parse raises.
- The watch and async-flush routes then clear the recorded error on that "clean" flush
  (`daemon.py:3219`, `:3532`).
- AC-5's non-UTF-8 file behaves the same way.

**Fold:**

- R2-sync takes refused paths out of `touched_existing`: no semantic pass, no `mark_tracked`.
- R2-sync orders the frontmatter check before the guard's `purge_path`, or states that the file
  is absent until fixed.
- AC-4 and AC-5 add a second `flush_queue`. It still refuses the file, the recorded error is
  still there, and `rmx daemon status` prints it.
- Per L139, the fold comes with a probe or RED test showing this.

**Pattern match:** YES, `imp-clear-on-the-failed-item` and `imp-requeue-needs-a-bound`. {#b1-body}

## Impressions {#impressions}

- When a spec says a refused or skipped file "stays" or "is retried", read every pass that runs
  after the refusal in the same batch. A later pass that stamps the mtime undoes the retry. {#imp-later-pass-stamps-the-refused-file}
- A row the code re-creates on every sync is not "legacy". Probe two syncs before you accept a
  guard built on the word; two specs (22.6 R4, bug-185 R10) inherited the premise. {#imp-legacy-row-recreated-each-sync}
- "Taken whole by reference" has to be checked against the source's ACs, mutations and census
  record, not its prose. The prose came across; the ACs did not. {#imp-whole-by-reference-check-the-acs}
- A producer census is not hypothetical when the store already holds 15,898 evidence-less edges
  on the verb. Find the writer (`link_part_of`) before you accept "one shipped entry". {#imp-census-find-the-writer}
- When a probe copies a store to compare replicas, keep the project directory's name, or the
  partition re-scope fakes the result. {#imp-replica-probe-keeps-dir-name}
