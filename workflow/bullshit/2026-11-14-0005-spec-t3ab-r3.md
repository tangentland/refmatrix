## Findings {#findings}

### SKETCHY: nobody owns the key that `pack` passes to `Held.covers` {#s1}

**Status:** new in r3, and unchanged at `153e95b` / `1be9b38`.

**What:**
- **25.1b doesn't say how `pack` derives the key.** `#k3` (`:94`): "a row whose key
  `held.covers(key, full_run_tier)` answers True". 25.1b never says how `pack` gets `key` from a
  row. `telemetry.item_key` does not appear in 25.1b.
- **10.2 h8 makes the key ONE function.** h8 (`:68`) reads "ONE function, `telemetry.item_key`, for
  the state, both renderers and 10.5's replay". 10.2's Files row builds `item_key` in
  `telemetry.py`.
- **But 10.2 can't wire it in.** 10.2's Files row now says `recall_pack.py`: "none".

**Why:**
- **25.1b builds first and must invent a key.** If its key differs from `HeldSet`'s `item_key`,
  `covers` never matches, and recall dedupe silently does nothing.
- **The fix lands in the wrong file.** 10.2 AC-1 catches the mismatch at RED, but only by editing
  a file 10.2 says it doesn't touch.
- **A name key merges distinct items.** It merges the same-name pairs that h8 exists to split.

**Fix:**
- 25.1b builds `telemetry.item_key` per h8, and `pack` calls it.
- Add an AC-25 leg: two same-name rows in different files, `covers` True for one key, and only
  that row moves.
- 10.2 h8 and its Files row cite 25.1b as the builder.

### SKETCHY: a later SessionStart can re-draw the session's fixed cell {#s2}

**Status:** new in r3, in t3b `151c81e`.

**What:**
- **10.2 R7 (`:197-199`):** "The SessionStart focus hook calls `arms.draw` ONCE, with `now` = the
  hook's time. It writes `stm/<session>.arm.json` (`{cell, period, t}`, temp-file + replace, one
  writer)".
- **The focus entry fires more than once per session.** Its matcher is
  `startup|resume|clear|compact` (`hooks.py:255-258` at `23caf45`). `resume` and `compact` keep
  the same session id.
- **"ONCE" is per hook run, not per session.** A `compact` or `resume` after the period's `end`
  re-draws at the new `now` and overwrites the file with `A+dedupe`.
- **So the "cannot flip midway" guarantee breaks** (L59: "so the factor cannot flip
  mid-session").
- **AC-11 misses it.** Its straddling leg checks prompts only, with no later SessionStart.

**Fix:**
- The arm file is written only when it is absent, at the session id's first SessionStart.
  `resume`, `clear` and `compact` keep it.
- Add an AC-11 leg: a session drawn inside the period, then SessionStart `compact` after `end`,
  keeps its cell.
- Mutation: the arm file overwritten on `compact`.
