### The lead's question: pass modules stay never allow-listable after 29.2 {#lead-bullet}

**Nothing contradicts it.**
- After 29.2 R7, docstrings and comments are outside the pass hash, so editing a stale phrase in
  either is free. A phrase in a hashed string literal is a behaviour change and should ride a
  re-derive, not an excuse.
- **One edge, not a contradiction.** 29.2 `#r7-refuse` hashes a pass file raw if it reads its own
  docstrings at run time. In such a file a docstring edit would still flip the pass, and the rule
  then forces the edit plus a re-derive. That is the honest cost, not a reason for an entry.
  Neither `session_ingest.py` nor `vectors.py` reads `__doc__` (grep: none), so AC-29's
  "normal digest does not move" holds for both.
- **The two allow lists are different things.** The clock-routing bullet in 29.4
  `#files-src-note` concerns the wall-clock census allow list (test sites), not the deferral
  guard's allow list. The rule is not contradicted there, but see M4 for the hand-off.
