## BULLSHIT {#bullshit}

### b-1: `v: 2` events are classified `malformed` {#b-1}

`telemetry.row_provenance` rejects `v != 1` (telemetry.py:1727); the spec says "R5's malformed rule does not change"
(spec:135) and D3 says no schema consumer has shipped. Consumers that break: 21.1's `events <ch> <stage>` funnel and 19.2's
fold (19.2 AC-16 classifies only through row_provenance). Tests pin the old rule:
`tests/test_task21_1_agent_usage_report.py:238` lists `{"v": 2}` as malformed; `tests/test_task21_1_emitters.py:204`
asserts `v == 1`. Fix: R2 changes R5 class 0 to `v not in (1, 2)` with a 21.1 revision row; move the bad case to
`{"v": 3}`; the emitters test asserts `v == 2`; an AC where a mixed v1/v2 file folds both in the existing funnel (RED at
HEAD: `malformed=N`).

### b-2: memories have no `Entity.path` {#b-2}

On the snapshot clone, all 153 distinct delivered memory ids and all 30 subjects have `path IS NULL`; the source file is
`memory_content.metadata.source_path` (488 of 622 memories). R2 says `Entity.path` / `item_meta e.path`, R3 "a memory's
path is its source file" (spec:157), AC-2 asserts that path. As written every prompt_recall delivery (348/348 since 11-10)
is `no_path` and the memory-Read leg is dead. Fix: name `source_path` as the memory path in R2 and R10; a memory without
one is null and counted; correct AC-2's RED.

### b-3: the Agent/Task leg and the `mcp__refmatrix__` skip are unreachable {#b-3}

The generated Pre/PostToolUse matcher is `Edit|Write|MultiEdit|NotebookEdit|Read|Bash|Grep|Glob` (hooks.py:292,296), and
the spec does not change hooks.py. Live since 11-10: 2,540 ring tool events — Bash 2,297, Read 86, Edit 83, Write 74; zero
Grep, Glob, Agent or mcp. AC-7 feeds Agent/mcp envelopes straight into `focus hook --event tool`, bypassing the matcher
(green in tests, never in production). Fix (user decision): extend the matcher (hooks.py + install-hooks regen + a
hook-cost line) OR drop both legs until 24.6's mod writes the ring (24.6 R3 sees every tool, carries `agentId`).
