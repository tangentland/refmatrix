## Findings {#findings}

### MEH: the standalone `rmx watch` flush runs on the Debouncer thread, so the root invocation never reaches it {#m1}

**File:** `task-26.5…:655-657`, `:1095`
**What:** the routes table reads "root `ctx.call_on_close`, plus each flush iteration **if the
watch loop is long-lived** (it opens its own invocation per flush)".
**Why:** `run_watcher`'s `flush` (`watch.py:155-158` at `b556bf3`) always runs on the
Debouncer's own `rmx-debounce` thread (`Debouncer.start` → `threading.Thread(target=self._loop)`).
The root group's contextvar invocation is never visible there, whatever the loop's lifetime.

There is a worse twist: `Debouncer._safe_fire` catches `Exception` and only prints
`[rmx watch] sync error: …` (`watch.py:127-131`). A `NoInvocationError`, or a missing per-flush
drain, would therefore be swallowed on that route, not raised loudly.
**Fix:**
- The per-flush invocation is unconditional, and it opens INSIDE `run_watcher`'s `flush` on the
  debouncer thread, so the library entry is self-bounded.
- Drop "if long-lived" and the root-drain claim from the table row.
- `_safe_fire` lets `NoInvocationError` propagate, or counts it as an error that reaches the CLI
  exit.
- (n)'s `rmx watch` row asserts the per-flush drain.

### MEH: (t)'s runtime leg checks after teardown and runs fixtures outside pytest {#m2}

**File:** `task-26.5…:928-933`
**What:** "by running each autouse fixture and asserting no invocation is open afterwards".
**Why:** the shape (t) must catch is a generator fixture (`with invocation(): yield`). Run to
completion, its invocation is closed again by "afterwards", so the runtime leg cannot fail on it.
Only the AST leg catches it, and the AST leg misses the spec's own allowed indirection: "a small
test helper that returns that context manager", called from a conftest fixture. Running fixtures
by hand, outside pytest's machinery, also breaks on fixtures that take `tmp_path` or
`monkeypatch`.
**Fix:** make the runtime leg a plain test that requests no fixtures and asserts
`memory_reroute.current() is None` in its body. Every autouse fixture applies to it
automatically, whatever the indirection. Add a `pytester` must-fail run with a planted autouse
fixture that goes through the helper.
