Under rule 9a this is an unanchored deferral. It also matches the filed pattern

### SKETCHY: the one-byte "on the wire" guards that make the budgets real are unpinned (3 mutations survive) {#s-1}

**Files:** three writers each hold back the newline they print:
- `cli.py` `_echo_pack` → `rec.echo(…, nl=False)`;
- `cli.py` `curator_status` → `fit_blocks(blocks, max(1, cap - 1), …)`;
- `cli.py` `scan_prompt_cmd` → `max_bytes=max(1, cap - 1)`.

`focus_context` and `recall-state` do the same.

**What:** these are what make "≤ N on what the agent receives" literally true. Without them, a
text of exactly N bytes plus click's newline is N+1 on the wire (the code's own comment,
2026-11-13). Spot-check results:

| Mutation | Tests run | Result |
|---|---|---|
| m2 `_echo_pack` `nl=False` → `nl=True` | `test_ac7_cli_prints_the_verbs_text_byte_for_byte`, `test_ac2_max_bytes_bounds_every_channel` (15) | **SURVIVED**, 16 passed |
| m3 curator `cap - 1` → `cap` | `test_ac12_curator_status_alone…`, `test_ac12_each_user_prompt_submit…` | **SURVIVED**, 2 passed |
| m4 scan-prompt `cap - 1` → `cap` | `test_ac12_scan_prompt_alone…`, `…each_user_prompt_submit…`, `ac2 … scan_prompt` | **SURVIVED**, 5 passed |

The boundary is reachable. `recall_pack.pack(5 rows, max_bytes=30)` and `(…, 60)` return payloads
of exactly 30 and 60 B (the loud-overflow path clips to N), so under m2,
`rmx memory recall --pack --max-bytes 30` would print 31. AC-7's assertion
`r.stdout.rstrip(b"\n") == res["text"]…rstrip(b"\n")` tolerates exactly the byte that m2 brings
back. None of AC-2 / AC-12's fixture payloads lands on N exactly.

**Why it's sketchy:** "never over N" (R8) is the headline claim of the task, and at the one place
it can fail, it is held up by comments.

**Fix:** add a CLI-level test at a tiny `--max-bytes` (the loud-overflow path, which yields
exactly N) asserting `len(stdout) <= N` for `memory recall --pack`, `scan-prompt` and
`curator status`. Drop the `rstrip(b"\n")` from AC-7. Effort: one parametrized test.

**Pattern match:** YES: `imp-printed-count-needs-a-fixture` and the 26.2 r1 "a 'says so' rule
needs its saying pinned". The invariant is stated, and the fixture never reaches its edge.
