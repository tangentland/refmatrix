## Why {#why}

Once grep is passive, the agent's only cue that the index knew something is gone. The user
approved a nudge (2026-10-07): one line, in the turn where it would help, instead of a rule the
agent has to remember. It must NOT touch grep's output. Grep is observed, not answered (the plan-16
rule), so the nudge is separate context added by a PostToolUse hook. {#why-body}

## Requirements {#requirements}

1. **R1 Trigger.** A PostToolUse(Bash) hook and a PostToolUse(Grep) hook fire when the command's
   or tool's pattern is identifier-shaped: a single token, matching
   `^[A-Za-z_][A-Za-z0-9_.:]*$`, optionally with `def ` / `class ` / `(` around it. The pattern
   comes from the same argv parser the learner uses (16.1), never a regex over the command line.
2. **R2 Content.** One line:
   `rmx: <symbol> is indexed — defined <path:line>; <n> callers, <m> tests (rmx context <symbol> --brief)`.
   It is emitted ONLY when the symbol resolves to a definition with ≥ 1 caller or test, which
   gates out the noise.
3. **R3 Budget.**
   - ≤ 1 nudge per symbol per session.
   - ≤ 10 per session.
   - A 300 ms hard deadline on the lookup (lock-free replica read). Past it, the hook is silent and
     counts a `nudge_timeout`.
4. **R4 Off switch.** `RMX_CONTEXT_NUDGE=0`, respected by the generated hook, and visible in
   `rmx learn status`-style output (`rmx hooks status`).
5. **R5 Generated.** The hook is GENERATED by `hooks.py` (never hand-authored), and
   `rmx install-hooks --check` covers it.

## Acceptance criteria {#acceptance}

1. `grep -n "_op_context" src/refmatrix/daemon.py` through the Bash hook path yields one nudge
   line naming `daemon.py:<line of def>`. A second identical grep in the same session yields none.
2. `grep -rn "error|warn" .` (not identifier-shaped) and a grep for an unindexed token yield no
   nudge.
3. The lookup p95 is ≤ 300 ms on a catalog copy of this repo, and over-deadline runs are counted,
   not printed.
4. 16.7's telemetry shows context calls per session before/after over ≥ 3 sessions. The result
   (rise or not) is reported in the summary. The nudge's value is measured, not assumed.
5. Mutations that must FAIL a test:
   - the per-session dedupe removed;
   - the gate on callers/tests removed;
   - the nudge written into the tool output instead of the hook context.
