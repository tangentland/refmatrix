### Run 1 and its fix (band fix first) {#run1}

Run 1 differed in **2 files, both for test-side reasons** (lane and image, not `src/`):

| Node | Host | Container | E line / reason |
|---|---|---|---|
| `test_sandbox_children.py::test_python_child_connecting_to_the_real_hub_socket_is_refused` | passed | failed | `PermissionError: [Errno 13] Permission denied: '/home/rmx/work/workflow/review-output/live-socket-touches.log'` |
| `test_sandbox_children.py::test_rmx_child_on_the_repos_live_store_is_refused` | passed | failed | `E       AssertionError: rmx exited 0 against /tmp/pytest-of-rmx/pytest-2/test_rmx_child_on_the_repos_li0/decoy/.refmatrix: 'not running\nsupervised: n/a (macOS only)\n'` |
| `test_models_offline.py::test_the_coderankembed_retriever_makes_no_call` | passed | skipped | `SKIPPED-UNPINNED … Skipped: CodeRankEmbed not cached` |

{#run1-table}

- **One cause for both `test_sandbox_children` failures.** The clone's tar listed only files, so
  `docker cp` created their parent directories as root, and the unprivileged user could not
  append to `workflow/review-output/live-socket-touches.log`. In the second test, the sandbox's
  refusal raised that `PermissionError` (an `OSError`) inside `daemon.read_pid`, which catches
  `OSError` and returns `None`; `rmx daemon status` then printed "not running" and exited 0.
  Fix: the tar carries every directory as its own entry owned by uid 1000, and the image
  creates `/home/rmx/work` owned by `rmx`. {#run1-fix-tar}
- **The skip.** The test needs `cornstack/CodeRankEmbed` (the eval retriever's model), which
  was not among the two default models copied in. Fix: the image carries it too (523 MiB;
  context 779 MiB). This goes past the spec's "two default models" because AC a1 requires the
  file to pass. {#run1-fix-model}
- A note for the lead, not a probe difference: `read_pid` turns a sandbox refusal that fails to
  log into "not running". The refusal still fires on the host, so this is not a `src/`
  difference between the lanes. {#run1-observation}
